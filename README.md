# Descarga de SpecGravity

Este repositorio solo sirve para **descargar** el framework SpecGravity del Taller de Agentes de IA. El código fuente es privado.

## Cómo descargarlo

Entra a **[telidmv.github.io/SpecGravity-descarga](https://telidmv.github.io/SpecGravity-descarga/)**, escribe la **contraseña temporal** que se entrega en la sesión del taller y presiona **Descargar**. La página te explica cómo guardarlo en tu carpeta de trabajo, extraerlo e instalarlo.

El archivo `SpecGravity.enc` está cifrado: sin la contraseña no se puede abrir ni ver su contenido. Se descifra en tu propio navegador; la contraseña no se envía a ningún servidor.
