# Descarga de SpecGravity

Este repositorio solo sirve para **descargar** el framework SpecGravity que se usa en el Taller de Agentes de IA. El código fuente es privado.

## Cómo descargarlo

1. Entra a **[Releases](../../releases/latest)** (a la derecha de esta página, o en el enlace).
2. En la sección *Assets*, haz clic en el archivo `SpecGravity_v<versión>.zip` para descargarlo.
3. Haz clic derecho en el ZIP descargado y elige **Extraer todo…**. Escoge la carpeta donde lo quieres, por ejemplo `C:\Proyectos\SpecGravity`.
4. Windows te pedirá una **contraseña**: es la contraseña temporal que se comparte en la sesión del taller.
5. Sigue la guía del Método 2 del material del taller (`03_Guia_Metodo_2`).

> Si no participaste en una sesión del taller, no tienes la contraseña. La contraseña cambia en cada grupo.

## ¿Problemas al extraer?

- **"Contraseña incorrecta":** revisa mayúsculas y minúsculas; cópiala y pégala.
- **Windows no pide la contraseña o da error:** instala [7-Zip](https://www.7-zip.org/) (gratuito), clic derecho en el ZIP, *7-Zip*, *Extraer aquí*.
